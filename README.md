
# Future Voice Network (FVN)

A digital platform supporting Banyamulenge students in accessing and continuing their education.

## Project Structure

- `frontend/` - Next.js web application.
- `backend/` - Node.js and Express API.
- `documentation/` - Project documentation.

## Technology

- JavaScript
- Next.js
- React
- Node.js
- Express.js
- Supabase PostgreSQL

Project setup in progress.
